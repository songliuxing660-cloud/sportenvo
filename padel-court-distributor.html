Partner FAQ

Contractor and distributor procurement questions.

Can a distributor standardize one padel court specification for every project?

A baseline specification can be standardized, but site-specific items such as wind exposure, foundations, roof interfaces, drainage and local approvals still need review for each project.

What documents should a contractor receive before installation?

The confirmed project package should include the relevant technical drawings, supplied-system specification, packing information and installation guidance, with local responsibilities clearly identified.

Who is responsible for foundations and local civil work?

Responsibility depends on the agreed commercial scope. The quotation should state clearly whether SPORTENVO supplies only the court package, a modular foundation option, technical interfaces or any additional support, while local civil work and approvals are defined separately.

Can SPORTENVO support private-label or repeat supply programs?

Project and OEM / ODM requirements can be discussed for repeat commercial supply, but the product specification, branding scope, documentation and order terms should be confirmed in writing.

How should distributors compare supplier quotations?

Normalize the quotations line by line: structure, glass, mesh, coating, turf, lighting, hardware, documents, packing, freight, foundation interface, installation support and warranty scope.

What information should a contractor send for the first project review?

Send the country, site type, court quantity, court preference, site dimensions, ground or building information, wind / climate conditions, foundation scope, delivery destination and installation responsibility split.
