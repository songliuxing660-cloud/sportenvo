Commercial Supply Specification

Reference modular steel foundation configuration.

The following values describe the SPORTENVO reference modular steel foundation configuration used for commercial project evaluation. Final geometry, loading, leveling range, anchors and site suitability remain project-specific.

Main beam100 × 200 × 3.0 mm reference main beam
Connection plates14 mm welded plate with 8 mm clamping plate in the reference configuration
Module format2 m × 2 m modular sections using 40 × 40 × 2.0 mm / 40 × 20 × 2.0 mm reference members
Deck board18 mm board, 1 m × 2 m reference format
Height adjustmentUp to 180 mm reference adjustment range for leveling coordination
Reference leg load2,765 kg per leg in the documented reference configuration; project load path still requires engineering review
Corrosion protectionHot-dip galvanizing plus powder coating in the reference configuration
Fasteners8.8-grade bolts with 304 stainless anti-theft caps in the reference configuration
Site requirementsGround capacity, levels, drainage, wind exposure, court loads, access and local engineering must be checked before approval
Engineering note. Reduced permanent civil work does not mean “no foundation engineering.” The ground, support reactions, leveling, drainage and anchoring strategy must be approved for the actual site.

Buyer FAQ

Commercial modular foundation supplier questions.

Does SPORTENVO supply modular padel court foundation systems?

Yes. SPORTENVO supplies modular steel foundation bases for selected commercial, leased and relocatable padel projects, subject to confirmed site and engineering requirements.

What is included in the reference modular foundation configuration?

The documented reference configuration includes 100 × 200 × 3.0 mm main beams, 14 mm welded plates, 8 mm clamping plates, modular steel sections, adjustable supports and project-specific fasteners and connections.

Can the modular foundation be supplied with the padel court?

Yes. The foundation base can be coordinated with compatible SPORTENVO court systems, technical drawings and project interfaces as one commercial supply scope.

What information is required for a modular foundation quotation?

Provide the project location, court quantity, ground or structural-deck condition, site levels, drainage, wind exposure, selected court model, roof requirement if any and installation access.

Is the modular foundation suitable for leased or relocatable sites?

It can be suitable for selected leased, temporary or relocatable projects where reducing permanent civil work is useful, subject to site and engineering review.

Where can I compare concrete and modular foundation options?

Use the Padel Court Foundation Guide to compare concrete and modular systems, ground conditions, drainage, leveling, anchoring and roof loads.

Project Fit

Is the Modular Foundation Base right for your project?

The modular base is a foundation strategy, not a substitute for site engineering. It is selected when permanent civil work, leveling or future relocation are key project constraints.

BEST FIT

Choose Modular Foundation when

  • The site is leased, temporary or expected to relocate.
  • Reducing permanent concrete work is commercially important.
  • Leveling flexibility is needed within the engineered adjustment range.
  • The project is paired with a Mobile Padel Court or other compatible system.
CONSIDER ANOTHER SYSTEM

Recheck the foundation strategy when

  • A permanent slab already exists and meets the project requirements.
  • A Roof adds significant structural reactions.
  • FORCE-HX high-wind loads require a different project-specific base review.
  • Ground conditions, drainage or level changes exceed the reference configuration.
