## Opportunity query decision rule

Only classify an **actual query exported from Bing** as actionable if it has commercial padel procurement / venue investment intent, matches a serviceable project in Europe, Australia or the Middle East, and can be answered factually. Discard irrelevant consumer, DIY, competing-brand and unsupported-country queries.

**Route queries to existing commercial pages and guides first.** If an existing page covers the query, enrich it with specific verified engineering parameters, assumptions, project references and relevant internal links rather than adding a duplicate article. New Buyer Guides require a demonstrated gap.

**No page Title, H1 or homepage Hero changes on this baseline date.** No SEO site changes or index submission are justified by missing AI citation data.
