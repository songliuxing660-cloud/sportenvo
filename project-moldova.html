Project Context

The completed venue integrates multiple padel courts within an existing enclosed structure, with spectator circulation and a dedicated lounge area alongside the courts.

Site Challenge

Site / Planning Challenge

The court package had to be coordinated with the existing enclosed hall, available clear height, lateral windows, circulation routes and the local assembly plan.

Indoor Installation

Court system planned for an existing enclosed industrial hall with high clear-height ceiling, natural light from large side windows and an active truss roof structure.

Multi-court Layout

The project required a multi-court court layout within the available hall dimensions, allowing for spectator circulation between courts.

Venue Integration

Project Coordination

Project-Specific Considerations

The indoor venue required coordination of the court layout with the existing hall structure, clear height, natural light, spectator circulation and the local installation sequence.

Indoor Hall Planning

  • → The venue uses an existing enclosed hall structure with a high clear-height truss ceiling, which accommodates the court structure without requiring ceiling modification.
  • → Large lateral windows provide natural daylight to the playing areas while maintaining a controlled indoor environment.
  • → The multi-court layout was coordinated within the available hall footprint, with spectator circulation space alongside the courts.
  • → Indoor installation reduces weather-related considerations for the court surface and structural connections.
  • → Installation was coordinated by a local team with technical support from SPORTENVO.

For court dimensions and site-planning guidance, see the padel court dimensions guide.
